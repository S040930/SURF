# AI-Marking：紧凑外部记忆评分研究

SURF 2026 · Project No. SURF-2026-0031

## 当前项目

本项目实现并评估 `r19-compact-external-memory-2026-08-v1`。研究以固定单模型、固定题目和固定人工参考标签为基准，比较：

- NM：无外部记忆；
- CRM：紧凑规则记忆；
- ARM：抽象量表记忆。

核心问题是，在相同同题历史评分证据、模型、更新次数与 token 预算下，局部条件规则记忆 CRM 与抽象分级量表记忆 ARM 是否产生不同的新答案评分误差。主要指标是题目等权 NAE，主要比较是 h=40 的 ARM−CRM；记忆组整体与 NM 的比较为次要。

## 已实现的平台边界

平台提供 r20 v2 提示词版本、持久化 48-call validation suite、冻结项目、独立实验组、持久化 Worker、调用尝试审计、记忆快照和三条件报告。每次评分只接收题目、当前答案和评分可见记忆；人工参考标签、人工反馈及记忆 support 不进入评分请求。CRM/ARM 快照受最多 6 项、397 个可见 token 和 555 个存储 token 限制（固定 `o200k_base`），并拒绝跨构念结构、具体或绝对评分语言、重复与答案复制。

## 实验规模与解释

每题固定 40 条记忆形成答案和 20 条共同测试答案，合计 380 次调用；3 题盲试点为 1,140 次，20 题正式实验为 7,600 次。正式实验只运行一次，因此结果只能描述该固定基准中的方向和不确定性，不能外推到其他模型、课程、题型、课堂流程或教师效率。

项目不实现也不声称实现 OCR、文件扫描、上传格式解析、教师时间节省、85% 准确率、60% 时间节省、隐藏思维链或跨题迁移。r18 与项目 1 是历史内部材料，不作为本研究证据。
