# r20 v1 prompt-design archive

This file marks the superseded `r20-saf-official-split-2026-08-v1` prompt
contract as historical and read-only. The exact v1 prompt strings and hashes
remain in the persisted `r20_prompt_versions` rows that produced v1 projects;
they must not be copied into, validated for, or executed by a v2 project.

The v1 contract used CRM items without `effect`, ARM `anchors` as an unstructured
string, three independent manual template trials, and the earlier calibrated
budgets. Those constructs are intentionally not reproduced as active copyable
prompt blocks here. The v2 normative source is
[`../r20-prompt-design.md`](../r20-prompt-design.md).
