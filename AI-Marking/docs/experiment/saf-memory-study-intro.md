# SAF 2.0 记忆研究：主题与背景

完整研究规格见 [V3-r2 研究设计](saf-memory-framework-design.md) 和
[运行手册](saf-memory-framework-runbook.md)。

## 研究主题

本研究考察：在短答题批改中，把历史人工批改案例交给评分模型，是否比无记忆基线更接近
人工分数。比较无记忆、普通完整案例检索、Mem0、A-MEM 四个条件，并对人工文字反馈做
可选消融。模型固定为 `gpt-6-luna`，结论限定在固定 SAF 2.0 题目范围内。

## 数据与研究问题

V3-r2 固定六道题：`12.2_PE`、`10.2_TC`、`8.2_MM`、`4.13`、`8.1_MM`、`4.3`。
每题 40 条训练答案和 10 条 `unseen_answers` 测试答案，训练与测试互斥；训练答案用于评分
和构建记忆，测试答案只在训练记忆提交后评分。每题有两个冻结历史顺序：数据集原始顺序，
以及随机种子为 42 的随机顺序。

主问题是记忆是否降低测试答案的归一化绝对误差（NAE）。次问题是 Mem0/A-MEM 与普通检索
的差异、去掉教师文字反馈后的变化，以及不同历史顺序对结果的敏感性。

## 评分边界

评分请求包含 `question`、`reference_answer`、`answer`、`score_floor`、`score_ceiling`
和 `memory`。参考答案只作为当前答案的内容标准，不写入历史记忆。`memory` 只向评分模型
暴露历史学生答案、教师分数和可选教师反馈；条件名、ID、相似度、rank、原始框架 payload
和验证反馈均不进入请求。分数允许连续小数，服务端拒绝越过题目级上下限的结果，不自动
四舍五入或裁剪。

## 设计原则

- 旧 `saf-memory-framework-v3` 项目作为历史基线保留；V3-r2 有独立协议 ID、manifest、
  scoring context 和 instrument hash，结果不得混合。
- 四个主条件保持 V3 的 40/10 队列、V4 的两种顺序、top-5 检索、训练评分和 NAE 主指标；
  no-feedback 仍是可选 wave，不新增 score-free 对照。
- 所有题目方差、分数 floor/ceiling、样本完整性、预期调用数和资源预算从六题数据重新审计，
  不直接继承旧 V3 的数据质量结论。
- 报告只做描述性分析，不使用显著性检验或总体推断；失败评分保持缺失。

## 当前状态

V3-r2 代码入口、六题数据选择、评分仪器指纹和审计路径已冻结。新项目默认使用
`saf-memory-framework-v3-r2`；旧项目只读，不会被新项目调用混入。V3 专属旧结果和本地
快照保留，V3-r2 的新工件使用独立项目目录。
