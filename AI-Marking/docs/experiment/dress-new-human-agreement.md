## 1. 研究定位

在 DREsS_New（Yoo et al., ACL 2025；2,279 篇韩国大学生 EFL 课堂作文，英语教育专家按
content / organization / language 三维 rubric 打分，1–5 分、0.5 步长）上，度量 LLM 评分代理
与真实人工标签的一致性。**本报告是描述性效度证据，不设自动通过或可发表阈值。**

这是同一数据集家族内的真实人工标签验证，**不是**独立外部语料验证（受限外推声明）。

## 3. 抽样设计（确定性的种子函数，可逐位重建）

- **技术试点**：池 = 1,966 − 96 尾部 = 1,870；五个综合分层各 6 篇 = **30 篇**；
  (分层 × 规范化题目) 格内按 `SHA-256(seed, key)` 升序取前 k。试点输入从正式池排除。
- **正式**：池 = 1,936；分层配额 **150 / 175 / 200 / 125 / 70 = 720**；
  96 篇尾部强制纳入（π=1，权重 1）；其余 624 个名额按 (分层 × 题目) 格做 Hamilton
  最大余数分配；格内入选概率 π = k_格 / N_格，设计权重 = 1/π。
  设计恒等式：Σ_全池 π = 720（测试钉死）。
- **复测**：从 720 篇正式样本中按层 **15 / 18 / 20 / 12 / 7 = 72** 篇再次独立调用。
- **调用总量**：正式 720×2 + 复测 72×2 = **1,584**；连试点共 **1,644**。

模型：`gpt-5.6-luna` 与 `gpt-5.6-terra`，均 `medium` 推理、`standard` 速度、`120s` 超时；
**仅模型标识不同**（比较模板强制校验对齐，不一致拒绝启动）。

## 4. 模型输入与输出契约

- 提示词信封由评分契约动态生成（标签盲）：rubric + `<prompt>` + `<essay>`；
  人工标签、分层、抽样层与权重信息**绝不进入模型输入**。
- 输出 JSON schema 由契约生成：仅含三个通道字段、`additionalProperties: false`、
  分值限定 0.5 网格；缺失、多余字段与非网格分一律拒绝并进入人工重试。
- 温度不可控披露：`codex exec` 不暴露温度控制。

## 5. 分析（锁定报告的内容）

每模型 × 每维（加权，设计权重 1/π；未加权仅作样本诊断）：
加权 QWK（10×10）、加权 MAE、Spearman（未加权，样本诊断）、精确一致率、±0.5 / ±1
一致率、校准曲线（预测分箱 → 人工均值）。

- **模型比较**：两模型共享同一批输入，逐维 QWK 差与 MAE 差的配对 bootstrap
  （5,000 次，种子化），百分位置信区间，仅作描述性比较。
- **基线**：`log(word_count) + prompt` 固定效应 OLS，10 折种子化交叉验证，确定性；
  明确标注为"篇幅与题目启发式基线"，不是人类评分替代品。
- **复测**：逐模型逐维完全一致率、平均绝对差、10×10 分数转移矩阵。
- **声明**：描述性证据不设阈值；配对比较仅描述；加权/未加权口径；受限外推；温度披露。
- 图表：3 张校准曲线 + 6 张复测转移矩阵（确定性 SVG，随报告哈希锁定）。

## 6. 可复现性
